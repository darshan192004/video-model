# Phase 1 — nginx Proxy, TLS, and Compose Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put an HTTPS nginx reverse proxy in front of the control-plane skeleton (Phase 0) using compose, with self-signed certs, proving the TLS + proxy + WebSocket path works end-to-end. **No authentication here** — OIDC/sessions land in Phase 1.5.

**Architecture:** Four containers share a private compose network: `nginx` publishes host `443` and reverse-proxies `http://controlplane:8000` (SPA HTML, `/api/*`, `/ws`). nginx terminates TLS (self-signed, generated by `gen-certs.sh`), honors WebSocket upgrades on `/ws`, disables buffering so job progress streams live, and raises `proxy_read_timeout` beyond one Wan render. ComfyUI (`comfyui:8188`) and control-plane (`controlplane:8000`) stay **internal-only**; no LAN publish of 8188/8000.

**Tech Stack:** Docker, Docker Compose, nginx (official `nginx:1.27` unprivileged variant), `openssl`.

**Spec:** `docs/superpowers/specs/2026-09-25-comfyui-app-mode-media-system-design.md` — Phase 1 implements §5.3, §5.5 (compose), §5.8 (gen-certs), §9 (proxy/TLS), §10 P1.

## Global Constraints

- Same compose base reused by later GPU + k8s phases — base must not hardcode GPU specifics.
- nginx image: `nginx:1.27-alpine` (unprivileged fallback `nginxinc/nginx-unprivileged:1.27-alpine` if the first can't run as non-root in this env). Pin the tag.
- **No `auth_basic`/htpasswd in nginx** — auth moves to the control-plane via OIDC (Phase 1.5).
- Certs live under `system/deploy/certs/` — MUST be `.gitignore`d.
- `DOMAIN` default `media.local`; self-signed SAN must include `localhost`, `127.0.0.1`, and `DOMAIN`.
- Internal network only; `comfyui:8188` and `controlplane:8000` never published to the host/LAN. Only nginx publishes.
- WebSocket location `/ws`: must send `Connection: upgrade` and HTTP/1.1, proxied to `controlplane:8000`.
- `proxy_read_timeout 3600s; proxy_buffering off;` on the whole `server`, not just `/ws`.
- No modifications to the Phase-0 ComfyUI or control-plane images.
- **Test environment (this machine only):** no GPU, no real weights, no 3090-box access. Every assertion in this phase runs on this host against the CPU-mode compose stack via `--resolve DOMAIN:PORT:127.0.0.1` loopback. The same assertions are later re-run inside k3s in Phase 5 (the project's primary test vehicle) by setting `NO_RESOLVE=1` (target already 127.0.0.1:PORT). Nothing here requires OIDC, CUDA, or a real GPU.

- [ ] **Step 1: Write `system/nginx/nginx.conf`**

Create `system/nginx/nginx.conf`:

```nginx
worker_processes auto;
pid /tmp/nginx.pid;
error_log /dev/stderr notice;

events {
    worker_connections 1024;
}

http {
    include /etc/nginx/mime.types;
    default_type application/octet-stream;

    log_format main '$remote_addr - $remote_user [$time_local] "$request" '
                    '$status $body_bytes_sent "$http_referer" '
                    '"$http_user_agent" ws=$http_upgrade';

    access_log /dev/stdout main;

    sendfile on;
    keepalive_timeout 65;

    # Values above 180s: a ComfyUI render can idle before emitting progress.
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
    proxy_buffering off;
    proxy_http_version 1.1;

    include /etc/nginx/conf.d/*.conf;
}
```

Use `/tmp` for pid/cache so the init process can run unprivileged.

- [ ] **Step 2: Write `system/nginx/conf.d/default.conf`**

Create `system/nginx/conf.d/default.conf` (final form — proxies everything to the control-plane, no basic auth):

```nginx
# Media System reverse proxy.
# Env-substituted at container start (envsubst '$DOMAIN'). Everything (SPA
# static + /api + /ws) proxies to the control-plane; ComfyUI is never exposed.

upstream controlplane_backend {
    server controlplane:8000;
    keepalive 16;
}

server {
    listen 443 ssl;
    server_name $DOMAIN;

    # Self-signed (internal), generated by scripts/gen-certs.sh.
    ssl_certificate     /etc/nginx/certs/fullchain.pem;
    ssl_certificate_key /etc/nginx/certs/privkey.pem;
    ssl_protocols       TLSv1.2 TLSv1.3;
    ssl_ciphers         HIGH:!aNULL:!MD5;

    # WebSocket endpoint (job progress stream) — must upgrade.
    location /ws {
        proxy_pass http://controlplane_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # Everything else is plain HTTP proxying to the control-plane.
    location / {
        proxy_pass http://controlplane_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

`$DOMAIN` is substituted by `envsubst '$DOMAIN'` inside the container; all `$http_upgrade`/`$host` nginx variables are untouched because envsubst is scoped to the single var list.

### Task 1.2: Cert generator

**Files:**
- Create: `system/scripts/gen-certs.sh`

**Interfaces:**
- Consumes: env `DOMAIN` (for CN/SAN) — default `media.local`.
- Produces: `system/deploy/certs/fullchain.pem`, `system/deploy/certs/privkey.pem` (gitignored).
- **No `gen-users.sh`:** authentication is delegated to the control-plane's OIDC flow (Phase 1.5), not nginx.

- [ ] **Step 1: Write `system/scripts/gen-certs.sh`**

Create `system/scripts/gen-certs.sh`:

```bash
#!/usr/bin/env bash
# Generate a self-signed TLS cert (internal use). Idempotent: refuses to
# overwrite existing files unless FORCE=1.
set -euo pipefail

DOMAIN="${DOMAIN:-media.local}"
CERT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/../deploy" && pwd)/certs"
mkdir -p "$CERT_DIR"

if [[ -f "$CERT_DIR/fullchain.pem" && "${FORCE:-0}" != "1" ]]; then
  echo "cert exists; set FORCE=1 to regenerate" >&2
  exit 0
fi

openssl req -x509 -newkey rsa:4096 -sha256 -days 825 -nodes \
  -keyout "$CERT_DIR/privkey.pem" \
  -out "$CERT_DIR/fullchain.pem" \
  -subj "/CN=${DOMAIN}" \
  -addext "subjectAltName=DNS:${DOMAIN},DNS:localhost,IP:127.0.0.1" >/dev/null 2>&1

chmod 600 "$CERT_DIR/privkey.pem" "$CERT_DIR/fullchain.pem"
echo "cert written: $CERT_DIR (fullchain.pem, privkey.pem)"
```

Make executable: `chmod +x system/scripts/gen-certs.sh`

### Task 1.4: Proxy + TLS + WebSocket test script

**Files:**
- Create: `system/tests/proxy_tls.sh`

**Interfaces:**
- Consumes: running compose stack at `DOMAIN:HTTPS_PORT` (resolved via `--resolve`).
- Produces: exit 0 when: `/` → 200 (SPA served through proxy); `/api/healthz` → 200 JSON; `/ws` upgrade → 101.
- Uses: `curl`, `openssl` (for `s_client` WS probe), env `DOMAIN`/`HTTPS_PORT`.

- [ ] **Step 1: Write `system/tests/proxy_tls.sh`**

Create `system/tests/proxy_tls.sh`:

```bash
#!/usr/bin/env bash
# Assert the proxy surface: TLS, SPA + control-plane reachability, WS upgrade.
# Reads DOMAIN/HTTPS_PORT/NO_RESOLVE env; NO_RESOLVE=1 targets a k3s
# NodePort directly (Phase 5 regression re-runs this in-cluster).
# Prereqs: compose stack up (Task 1.3).
set -euo pipefail

DOMAIN="${DOMAIN:-media.local}"
PORT="${HTTPS_PORT:-443}"
BASE="https://${DOMAIN}:${PORT}"
if [[ "${NO_RESOLVE:-0}" == "1" ]]; then RESOLVE=""; else RESOLVE="--resolve ${DOMAIN}:${PORT}:127.0.0.1"; fi

fail() { echo "ASSERT FAIL: $*" >&2; exit 1; }

echo "[1] / (SPA through proxy) => 200"
code=$(curl -sk -o /dev/null -w '%{http_code}' $RESOLVE "$BASE/")
[ "$code" = "200" ] || fail "expected 200 got $code"
curl -sk $RESOLVE "$BASE/" | grep -q "Media System" || fail "SPA HTML not served"

echo "[2] /api/healthz via proxy => 200 JSON"
code=$(curl -sk -o /dev/null -w '%{http_code}' $RESOLVE "$BASE/api/healthz")
[ "$code" = "200" ] || fail "expected 200 got $code"
body=$(curl -sk $RESOLVE "$BASE/api/healthz")
echo "$body" | grep -q '"status"' || fail "healthz missing status: $body"

echo "[3] /ws upgrade => HTTP/1.1 101"
if command -v websocat >/dev/null 2>&1; then
  ws_code=$(websocat -E --url "wss://${DOMAIN}:${PORT}/ws" 2>&1 | head -1) || true
  echo "$ws_code" | grep -qi "101" || fail "websocat ws not 101: $ws_code"
else
  echo "[3-skip] websocat not installed; probe via openssl..."
  handshake=$(printf 'GET /ws HTTP/1.1\r\nHost: %s\r\nUpgrade: websocket\r\nConnection: Upgrade\r\nSec-WebSocket-Key: dGhpc2lzYXRlc3RrZXk\r\nSec-WebSocket-Version: 13\r\nOrigin: https://%s\r\n\r\n' \
    "$DOMAIN" "$DOMAIN" \
    | timeout 5 openssl s_client -quiet -connect "127.0.0.1:${PORT}" -servername "$DOMAIN" -CAfile /dev/null 2>/dev/null | head -1 || true)
  echo "$handshake" | grep -q "101" || fail "ws not 101: $handshake"
fi

echo "PROXY/TLS: all assertions passed"
```

Make executable: `chmod +x system/tests/proxy_tls.sh`

> No HTTP-401 assertions exist here: authentication is the control-plane's OIDC job (Phase 1.5), not nginx's.

## Phase 1 Exit Criteria

1. `docker compose up` brings up nginx + control-plane + postgres + comfyui; `nginx:443` answers HTTPS.
2. `curl -sk https://media.local:443/` → `200` (SPA HTML); `/api/healthz` → `200 {"status":"ok"}` (no auth).
3. `/ws` upgrade handshake → HTTP `101` (through nginx).
4. ComfyUI and control-plane and postgres ports are NOT published to the host (internal-only).
5. `git status` clean except ignored `deploy/certs`, `.env`.
6. No change made to `comfyui-media:0.1.0` or `controlplane-media:0.1.0` images.
