### Task 4.2: `ship-image.sh` — four images (DRY_RUN tested locally)

**Files:**
- Create: `system/scripts/ship-image.sh`

**Interfaces:**
- Consumes: images `comfyui-media:0.1.0`, `controlplane-media:0.1.0`, `postgres:16-alpine`, `nginx:1.27-alpine`; SSH alias env `SSH_ALIAS` (default `media3090`).
- Produces: on the box — the four images loaded + repo subtree (minus `.git`, `models`, certs/secrets, `.env`); on this machine — `DRY_RUN=1` writes the archive(s) to prove `docker save` works. Real `ssh`/`rsync` are `[DEFERRED-REAL]`.

- [ ] **Step 1: Write `system/scripts/ship-image.sh`**

```bash
#!/usr/bin/env bash
# Ship the four stack images + the system subtree to the 3090 box.
# DRY_RUN=1: only save image archives locally (tests the save path here).
set -euo pipefail

ALIAS="${SSH_ALIAS:-media3090}"
IMAGES=("comfyui-media:0.1.0" "controlplane-media:0.1.0" "postgres:16-alpine" "nginx:1.27-alpine")
STAGE="$(mktemp -d)"
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"

for img in "${IMAGES[@]}"; do
  docker image inspect "$img" >/dev/null || { echo "image $img missing" >&2; exit 1; }
done

echo "[1] save each image"
for img in "${IMAGES[@]}"; do
  tag="${img//[:\/]/_}"
  docker save -o "$STAGE/$tag.tar" "$img"
  ls -lh "$STAGE/$tag.tar"
done

if [[ "${DRY_RUN:-0}" == "1" ]]; then
  echo "DRY_RUN: tar archives created; skipping ssh/rsync (stage: $STAGE)"
  exit 0
fi

echo "[2] ssh load (4 archives)"
for img in "${IMAGES[@]}"; do
  tag="${img//[:\/]/_}"
  ssh "$ALIAS" "docker load -i /dev/stdin" < "$STAGE/$tag.tar"
done

echo "[3] rsync system subtree -> ~/media-system on the box"
rsync -az --delete \
  --exclude '.env' --exclude '.gitignore' \
  --exclude 'deploy/secrets' --exclude 'deploy/certs' \
  --exclude 'models' --exclude 'tests/artifacts' \
  "$ROOT/" "$ALIAS:media-system/"
rm -rf "$STAGE"
```

- [ ] **Step 2: Test the local archive path** — `DRY_RUN=1 bash system/scripts/ship-image.sh` prints `DRY_RUN: tar archives created; skipping ssh/rsync` and all four tarballs are non-empty.

- [ ] **Step 3: Commit** — `feat: ship-image for four stack images (DRY_RUN validated)`.

### Task 4.3: `gpu-smoke.sh` dual-mode (control-plane on the box)

**Files:**
- Create: `system/tests/gpu-smoke.sh`

**Interfaces:**
- `--validate-shape` (runs here): asserts the four production workflows are complete API-format JSON, all referenced `.safetensors` names exist in `models.manifest.json` (lockstep), `config/templates.schema.json` keys align with each workflow (same checks as P2's `workflow_schema.sh`), and **no** `extra.appMode`/App-Mode fields are present. Runs entirely here, no GPU.
- `--deploy` (user box only, `[DEFERRED-REAL]`): OIDC login (org issuer via the SPA's `/api/auth/start`), submit each workflow **through `/api/jobs`** at reduced steps, poll to `success`, assert gallery artifacts, capture a VRAM csv (`nvidia-smi` samples during the run). The user executes this per the runbook.
- Workflow API-prompt construction is identical between modes (only the network/auth target differs), and it reuses the P2 injection contract.

- [ ] **Step 1: Write `system/tests/gpu-smoke.sh`**

```bash
#!/usr/bin/env bash
# GPU/workflow validation. Two modes:
#   --validate-shape   (THIS MACHINE): parse + lockstep + schema + no-appMode, no GPU.
#   --deploy           (USER BOX, DEFERRED): login via org SSO -> submit 4 workflows
#                        at reduced steps through the control-plane -> gallery + VRAM csv.
set -euo pipefail
MODE="${1:---validate-shape}"
ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
bow() { echo "FAIL: $*" >&2; exit 1; }

case "$MODE" in
  --validate-shape)
    echo "== validate-shape (this machine)"
    [[ -f "$ROOT/config/models.manifest.json" ]] || bow "missing manifest"
    [[ -f "$ROOT/config/templates.schema.json" ]] || bow "missing templates.schema.json"
    for wf in qwen-t2i qwen-edit wan-t2v-a14b wan-i2v-a14b; do
      file="$ROOT/workflows/$wf.json"
      jq empty "$file" || bow "$wf not valid json"
      jq -e --arg n "1" 'has($n) and (to_entries[0].value | has("class_type"))' "$file" \
        >/dev/null || bow "$wf not API format"
      jq -e '.extra?' "$file" >/dev/null 2>&1 && { grep -q appMode "$file" && bow "$wf contains appMode"; } || true
      refs=$(jq -r '..|objects|.unet_name?,.name?,.clip_name?,.vae_name? // empty' "$file" 2>/dev/null | grep -E '\.safetensors$' | sort -u)
      for r in $refs; do
        grep -q -- "$r" "$ROOT/config/models.manifest.json" || bow "$wf references unknown weight $r"
      done
    done
    bash "$ROOT/tests/workflow_schema.sh"   # classes in /object_info + bind alignment
    echo "  shape OK (workflows API-format, lockstep, schema aligned; no appMode)"
    ;;

  --deploy)
    echo "== deploy (USER BOX ONLY; DEFERRED)"
    # Real flow (written fully in docs/ops/gpu-wire-up.md, Task 4.5):
    #   1. browser/curl /api/auth/start -> org Dex SSO w/ the box's .env OIDC creds
    #   2. for each template in {qwen-t2i, qwen-edit, wan-t2v-a14b, wan-i2v-a14b}:
    #        POST /api/jobs at reduced steps (steps*0.5, min 4) + sample nvidia-smi csv
    #        poll /api/jobs/{id} to success; assert /api/gallery/{id}/file 200
    #   3. write tests/artifacts/gpu-smoke-<date>.csv + .log
    ;;
esac
```

- [ ] **Step 2: Run validate-shape here** — `bash system/tests/gpu-smoke.sh --validate-shape` → `shape OK …`.
